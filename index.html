Things I've grown.

ScaleTrain ↗

Fault-tolerant distributed training on SLURM

Scaled a 30M-parameter transformer across 4×A100s at 500K tokens/s with PyTorch DDP. Signal-driven checkpointing and deterministic sharding resume from the exact interrupted step: zero lost work, verified by 64 tests.

PyTorch · DDP · SLURM · NVIDIA A100

VideoQuery ↗

Semantic video search with grounded answers

Multimodal search and Q&A over video with timestamped citations. Fused BM25, dense, CLIP, and caption retrieval with RRF + reranking: 88.5% R@1 and 3.9 s temporal error. Crash-safe ingestion at 10× real time on AWS.

Whisper · CLIP · pgvector · AWS

AgentXAI ↗

Traceable explainability for multi-agent AI

Tackles unfaithful explanations in agentic systems: a 5-agent architecture with typed traces, causal DAGs, evidence constraints, and counterfactual ablations, reaching 93% explanation sufficiency and 0.71 stability.

LangChain · FAISS · FastAPI · Streamlit

FlexStore ↗

An S3-inspired distributed object store

Go object store with 3× replication across 5 nodes: 528 MiB/s writes, 2.6 GiB/s reads. Heartbeat failure detection re-replicates lost chunks in 8-13 s with 100% read availability and SHA-256-verified, byte-identical recovery.

Go · gRPC · PostgreSQL · Docker

GraphRec

Personalized PageRank recommendation at scale

Recommender over a 31.8M-rating bipartite graph of 200,948 users, built on sparse matrices. Eliminated 25 GB of per-query dense allocation and reached 0.280 Hit Rate@10 vs a 0.160 collaborative-filtering baseline, backed by 197 tests.

Python · SciPy · Streamlit · Docker

ConvLoRA ↗

Parameter-efficient transfer learning, from scratch

Convolutional LoRA implemented from scratch in PyTorch for ResNet-18 transfer. 59.34% CIFAR-100 accuracy with just 3.01% of full fine-tuning's parameters, cutting catastrophic forgetting from 5.06 to 1.98 points.

PyTorch · ResNet-18 · LoRA

SentryFlow ↗

Real-time rate limiting & usage analytics

Kubernetes rate-limiting platform on AWS serving requests at <100 ms, with token-bucket and sliding-window controls, JWT auth, Kafka ingestion, and a React dashboard for live usage analytics. 92% test coverage.

Go · Kubernetes · Kafka · React

MLflow · DVC · Docker · FastAPI
